# c-practice

C言語の学習記録です。基礎文法からアルゴリズムまで、書いたコードを置いています。

## 構成

| ディレクトリ | 内容 |
|---|---|
| `01_basics/` | 基本文法（入出力、条件分岐、ループ） |
| `02_algorithms/` | アルゴリズム（ソート、探索など） |

## ビルドと実行

```sh
make                      # すべてビルド
./01_basics/fizzbuzz      # 実行例
make clean                # 生成物を削除
```

環境：gcc（C11）
